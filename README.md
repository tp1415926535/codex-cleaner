# Codex Cleaner

**简体中文** | [English](README.en.md)

一个运行在 Windows 本机的 Codex 清理工具，包含会话管理、数据库维护和文件清理。通过浏览器查看空间占用、预览内容，并清理不再需要的会话、旧日志、缓存和暂存残留。

工具只监听本机地址 `127.0.0.1`，不上传会话内容。日常使用无需安装 Node.js、前端依赖或额外数据库。

## 功能

- **查看空间占用**：按大小或最后活动时间排序，支持搜索、项目筛选和项目导航。
- **查看会话关系**：将能够确认归属的子代理任务、安全审批挂到父会话下，默认收起附属项。
- **预览内容**：点击标题查看用户消息、回复和相关文件，支持分页加载、调整预览宽度和清空预览。
- **批量清理**：支持单选、全选、项目分组选中和未关联记录分组选中。
- **清理缺失文件的残留记录**：筛选“文件全部缺失”，通过官方 CLI 清理对应会话记录。
- **数据库维护**：回收数据库空闲空间，并可按保留时间清理运行日志。
- **文件清理**：扫描整个数据目录，自动选择适合清理的旧日志、缓存及暂存残留；生成产物和配置备份可手动选择。
- **中文 / English**：首次按浏览器首选语言选择，手动切换后记住偏好。

每次打开或刷新页面默认进入“会话”。各页的勾选、筛选和分组设置仍会保存。

## 使用前准备

- Windows。
- Python 3.10 或更新版本，并确保 `python` 或 `py` 命令可用。
- 本机已有 Codex 会话数据。
- 删除会话需要兼容的 Codex CLI；工具会尝试自动发现。

**无需固定 CLI 版本。** 工具会检测官方删除命令，并在隔离的临时数据目录中自动验证：占用中的会话不能删除，其他会话可删除，释放锁后可删除原会话。验证只使用临时测试会话，不接触你的真实会话。验证通过后启用删除；失败时顶部会显示只读状态及原因。Python 主要在 Windows / Python 3.13 环境验证。

## 快速开始

下载或克隆项目后，双击 `start.cmd`。工具启动后会自动打开浏览器，并扫描本机 Codex 数据目录。

也可以在项目目录运行：

```powershell
python app.py
```

默认地址为 `http://127.0.0.1:8765`。端口被占用时会使用其他空闲端口，以启动窗口显示的地址为准。保留启动窗口；关闭窗口会停止服务。

### 指定数据目录或端口

```powershell
# 使用指定的 Codex 数据目录
python app.py --home "D:\CodexData"

# 手动指定官方 CLI
python app.py --cli "C:\path\to\codex.exe"

# 指定端口，不自动打开浏览器
python app.py --port 8766 --no-browser
```

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--home` | Codex 数据目录 | `CODEX_HOME`，未设置时为用户目录下的 `.codex` |
| `--cli` | Codex CLI 可执行文件路径 | `CODEX_CLEANER_CLI`，未设置时自动发现 |
| `--port` | 优先使用的本机端口 | `8765` |
| `--no-browser` | 启动时不打开浏览器 | 默认打开 |

右上角“设置”也可以修改数据目录和 CLI 路径。保存后自动检测并加载会话；这些设置仅对本次运行生效，不修改 Codex 自身的配置。

## 管理与清理会话

顶部提供“会话 / 数据库维护 / 文件清理”三个页面。各页面的选择按数据目录保存，切换页面或刷新后恢复；会话扫描未完成时不会清空已保存的选择，扫描完成后剔除已不存在的目标。

### 浏览列表

等待首次扫描完成后，可以搜索标题、项目、路径或会话 ID，也可以按文件状态筛选。打开“按项目分组”后，左侧导航支持快速跳转项目。

会话与附属记录在同一个列表中显示：

- 能确认父子关系的记录挂在父会话下，默认收起，需要时可展开。
- 勾选父会话会同时勾选全部已关联子项，收起状态不影响联动选择。
- “未关联记录”表示目前无法关联到现存父会话，**不等于无用记录或可自动删除的垃圾**。
- 筛选命中子项时，父会话可能作为层级说明显示。不符合筛选的说明行不能勾选，也不参与全选。

关系来自 Codex 数据库和日志文件头中的明确字段，不会仅凭项目相同或时间相近推测关联。

### 预览内容

点击标题，在右侧查看内容。可以拖动预览区边界调整宽度，或使用“清空预览”取消查看。

预览侧重用户消息和能够识别的助手回复，不是完整聊天导出。图片显示占位信息；超大消息、部分旧版记录或未标记为最终回复的内容可能被省略。

### 删除会话

1. 勾选需要清理的记录。表头复选框选择当前筛选结果；分组复选框只选择本组匹配记录。
2. 点击“查看删除计划”，核对待删除会话、附属项和预计空间。
3. 确认永久删除，等待执行结果。无需逐条输入确认文字。

**删除不可撤销，工具不提供回收站或自动备份。** 切换筛选条件不会清空此前选择，请以底部已选统计和删除计划为准。

删除通过官方 CLI 执行。工具会检查会话元信息、历史索引及原关联文件的清理结果，不会仅凭命令退出成功就认定清理完整。批量删除按顺序执行，可停止后续删除；已经完成的删除无法撤回。

Codex 可以保持运行。当前会话、占用中、状态无法确认或文件归属存在冲突的目标会受到保护，工具不会强制关闭 Codex 或解除其占用。

### 清理文件缺失的记录

选择“文件全部缺失”，再使用表头或分组复选框批量选择。正常父会话不会仅因为子项文件缺失而被选中。

这些记录可能来自此前手动删除的文件。清理的是残留会话记录，因此即使成功，释放空间也可能显示 **0 B**。“无法读取”与“文件不存在”是不同情况，不会按同一种方式处理。

## 数据库维护

点击页面顶部的“数据库维护”，可以查看以下数据库的占用与内部空闲空间：

| 数据库 | 主要内容 |
| --- | --- |
| `thread_history_1.sqlite` | 对话轮次、消息和历史索引 |
| `state_5.sqlite` | 会话元信息、项目及相关状态 |
| `logs_2.sqlite` | Codex 运行诊断日志 |

### 删除记录与释放空间有什么区别？

删除会话会调用官方命令清理对应记录，但 SQLite 通常会保留删除后空出的页面供后续写入，数据库文件不一定立即变小。

数据库维护用于整理这些空闲页面、回收文件空间。可以清理完一批会话后统一执行，不必每删除一条就整理一次。

### 如何维护

1. 选择需要整理的数据库。
2. 默认保留全部日志，仅回收空闲空间。如需清理日志，可选择保留最近 7、30、90 天，或清理计划时间之前的全部日志。
3. 查看维护计划并确认执行。
4. 查看各库的完成状态及实际回收量。

维护会保留现有会话和历史记录，不会因某条历史记录缺少会话元信息就自行删除它。数据库不会被整文件删除。

整理需要临时磁盘空间。数据库忙、可用空间不足或检查失败时会报告原因。维护支持停止，但已经提交的日志删除不会撤回；维护、会话删除与扫描不能同时执行。

## 常见问题

### 如何清理缓存、临时目录和生成产物？

打开“文件清理”，立即显示目录和列表占位；优先检查常见清理目录，检查进度和已完成目录的文件分批显示，检查期间可以预览。完整检查后才更新清理建议并启用选择。首次检查会自动勾选建议项，也可点击“自动选择建议项”重新选择。默认选择超过 7 天的可清理内容，可切换为 30 或 90 天。支持路径搜索、建议类型筛选，以及查看全部一级目录的大小。单文件可直接预览；多文件目录通过“查看文件”打开完整文件列表，支持搜索和分页，每页 100 个文件。列表显示相对路径，图片有缩略图并可放大，文本文件支持内容预览；主列表、查看窗口和所选文件都有“打开文件夹”，在 Windows 资源管理器中打开目录或定位文件。打开、搜索和翻页复用检查时的文件清单，不重新扫描整个数据目录；单文件先显示已有元信息，正文在详情区域独立加载，删除仍会重新检查。文本预览最多读取 256 KiB，图片预览支持 PNG、JPEG、GIF、WebP、BMP 和 ICO，单张不超过 16 MiB；HTML 和 SVG 显示为文本。查看窗口和图片放大的关闭入口统一为右上角 × 图标，也支持 Esc。

列表默认按一级文件夹分组，根目录中的文件单独成组。组标题显示清理项数、文件数和大小；多项分组可折叠，组复选框仅选择当前筛选命中的可清理项，受保护项保持未选。分组和表头复选框按当前筛选中的全部项显示全选、半选或未选；有受保护项未选时显示半选。可切换为平铺列表，分组和折叠状态随选择一起保存。顶部统计使用紧凑状态栏。左侧目录导航显示各一级目录的总占用和文件数，支持目录搜索、展开并跳转到对应分组；没有可清理项的目录会显示保留提示。移动端将导航放在列表上方。

自动建议包含旧沙箱日志、旧执行器、部分工具缓存、已知暂存目录及失败的状态写入残留。当前和最近版本的执行器、配置引用的路径、正在使用的任务、链接、无法读取的内容及仍在保留期内的文件受到保护。已安装插件、技能、认证、规则、记忆和数据库文件不会通过文件清理直接删除。

可视化、生成图片、附件、计划和配置备份按需手动选择，不自动勾选。点击“查看删除计划”，核对路径和空间后确认永久删除。执行前重新检查整个选择；文件变化、占用或权限问题会阻止删除。可停止后续清理，已经删除的文件无法恢复。根目录及锁文件保留，只移除选中范围内已清空的任务或暂存目录。

### 为什么列表大小与删除计划大小不同？

会话行的大小包含官方已知子会话的文件大小；通过日志文件头补充显示的附属关系不一定属于同一官方删除范围。勾选父项后，这些附属记录也会作为选中项进入计划，因此最终范围应以删除计划为准。

会话空间统计是可确认归属的 JSONL 文件逻辑大小，不包含共享数据库、图片附件或文件系统压缩差异。数据库维护单独统计数据库及 WAL 文件；实际磁盘剩余空间的变化也可能受到 Codex 同时写入的影响。

### “扫描问题”是什么？

扫描发现的文件缺失、读取失败、路径异常或归属不明等情况。点击状态栏中的“扫描问题”查看明细；需要重新核对文件时，可在该窗口使用“重新检查文件”。问题数量不是待清理文件数量，也不是可释放空间。

### 为什么有些记录不能删除？

可能是会话正在被 Codex 占用、CLI 删除能力或会话锁验证未通过、权限不足，或文件归属无法确认。查看顶部 CLI 状态、设置中的连接详情、删除计划或执行结果中的具体原因。工具不会绕过这些检查直接删除文件。

占用状态约每 6 秒自动更新，无需退出整个 Codex。更新 CLI 后，可在“扫描问题”中点击“重新检查文件”，或保存设置以重新验证 CLI。若提示验证未通过，关闭 Codex 不会解除该限制。

### 切换语言会修改会话内容吗？

不会。语言切换只影响界面，会话标题、消息正文、项目名和路径保留原文。首次打开时，中文浏览器首选语言使用中文，其他语言使用英文；已有手动选择时优先使用保存的偏好。

## 开发

后端使用 Python 标准库，前端使用原生 JavaScript、HTML 和 CSS。

```text
app.py          本地 HTTP 服务与启动入口
cleaner/        会话扫描、官方 CLI 清理和数据库维护
web/            页面、样式和前端逻辑
web/locales/    中文与英文语言资源
tests/          自动测试与开发验证脚本
```

运行自动测试：

```powershell
python -m unittest discover -s tests -v
```

浏览器验证脚本使用 Playwright，仅开发验证需要 Node.js 和 Playwright。运行前阅读相应脚本的服务地址、模拟接口及环境变量配置。官方 CLI 的隔离验证脚本为 `tests/probe_official_delete.py`，它会创建并删除临时测试会话。

新增界面文案应同步更新 `web/locales/zh-CN.json` 和 `web/locales/en.json`。不要提交本机 Codex 数据、会话内容或包含私人信息的调试截图。
